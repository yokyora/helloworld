# Hello World

YOKYORA 的 Windows 桌宠项目。目前包含基础桌宠与 DeepSeek 聊天接入，不是完整的长期记忆陪伴产品。

## 当前可用

- 待机只显示角色，窗口缩为 180 × 180；点击或右键角色打开 300 × 360 快捷入口，聊天、设置和隐私按需展开为 440 × 560。尺寸为逻辑像素。
- 按住角色拖动；点击角色、面板收起按钮或 Esc 回到待机。快捷入口保留休息、勿扰、最小化和退出。
- 原生阴影关闭，展开面板保留浅色内侧描边。聊天草稿在切换和收起面板时保留；收起不会取消生成，停止需点击聊天中的「停止回复」。
- 临时 CSS 角色：待机浮动、戳一戳反馈、休息闭眼、叫醒。
- 勿扰暂停动画和戳戳反馈，选择保存到本机；休息仅本次运行生效，并停止当前生成。
- DeepSeek 流式文字聊天、停止回复、有限近期上下文、本地聊天记录与确认后清空。
- 设置页可选 Flash/Pro、输入或移除密钥、授权或停止后撤销远程发送。密钥由 Windows 当前用户 DPAPI 加密保存，不读回前端。
- SQLite 数据层、Rust 统一状态与任务管理、单实例运行；浏览器预览不调用模型。
- 键盘可操作按钮，Esc 收起说明面板，遵循系统减少动画偏好。

尚未实现：长期记忆抽取与检索、屏幕感知、外部软件操作、托盘、位置记忆、角色轮廓级鼠标穿透、正式角色素材。右键角色打开的是应用内快捷入口，不是系统菜单。

## 配置 DeepSeek

1. 启动桌面程序，点击角色，再打开“设置”。
2. 选择模型，填写你自己的 DeepSeek API Key。密钥不要写进仓库或发送到聊天里。
3. 阅读并勾选远程发送授权，保存设置。保存不会发起模型请求。
4. 打开“聊天”，主动发送消息。未配置密钥或未授权时不能发送。

默认使用 `deepseek-flash` 非思考模式，可选 `deepseek-v4-pro`。请求仅发往 DeepSeek 官方接口，不接受自定义服务地址。停止回复不会撤销服务端已处理的计算或费用。密钥不从其他应用或环境变量自动读取。

数据保存在 Tauri 应用本地数据目录的 `companion.sqlite3`，通常是 `%LOCALAPPDATA%/com.yokyora.helloworld/`，与源码分开。清空对话只删除本机业务记录，不删除服务端数据；移除本机密钥不等于在 DeepSeek 平台撤销密钥。

## 开发

需要可运行的 Node.js/pnpm，以及 Windows 上的 Rust MSVC 工具链、C++ 构建工具和 WebView2。具体本机路径统一查全局 `AGENT_ENVIRONMENT.md`，本仓库不维护环境清单副本。

在本仓库根目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm dev                 # 仅浏览器预览，不具备原生窗口能力
pnpm tauri dev           # 原生桌宠开发
```

构建检查：

```powershell
pnpm build
cargo build --locked --manifest-path src-tauri/Cargo.toml
cargo test --locked --manifest-path src-tauri/Cargo.toml --lib
```

构建不依赖开发服务器的本地调试程序（不生成安装包）：

```powershell
pnpm build
cargo build --locked --features tauri/custom-protocol --manifest-path src-tauri/Cargo.toml
```

程序位于 `src-tauri/target/debug/helloword-tauri.exe`。文件名沿用原工程名称。它是开发调试产物，未签名、未发布，不代表完成分发验收。
