# 启动步骤

## 环境

- Node.js 22
- pnpm 11
- Rust stable（`x86_64-pc-windows-msvc`）
- WebView2
- Visual Studio 2022（MSVC，`cl` 不必在 PATH）

## 步骤

在项目根目录执行：

```powershell
pnpm install
pnpm tauri dev
```

`pnpm tauri dev` 会先起 Vite，再编译并打开桌面窗口。首次编译会拉取 crates，约两分钟。

## 启动后

- 前端：http://localhost:1420/
- 窗口标题：`helloword-tauri`
- 进程：`target\debug\helloword-tauri.exe`

只看页面、不编译桌面端：

```powershell
pnpm dev
```

停止：关掉窗口，或在该终端按 Ctrl+C。
