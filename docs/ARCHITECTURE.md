# Hello World 应用架构

决策日期：2026-10-26。用户已确认先采用远程 API，并明确指定 DeepSeek，由用户自行配置服务密钥。本地推理暂不实现。本文记录本次落地结果；旧需求文档保留为历史方案，不再将其全部选型视为当前实现。

## 技术选择与边界

| 层 | 当前选择 | 责任 |
| --- | --- | --- |
| 桌面壳 | Tauri 2 / Windows WebView2 | 窗口、生命周期、单实例 |
| 界面 | React 19 / TypeScript / Vite | 呈现、输入、动画、流式文字展示 |
| 应用核心 | Rust | 权限检查、请求排他、取消、状态版本、业务编排 |
| 数据 | rusqlite / 内嵌 SQLite | 设置、对话轮次、状态与来源时间 |
| 模型 | DeepSeek 官方 Chat Completions | Rust 发起 HTTP 请求，SSE 流式接收 |
| 密钥 | Windows 当前用户 DPAPI | 加密后保存；不从后端读回明文到界面 |

没有独立后台服务器、Python、Ollama 或外部数据库要求。WebView2 仍是 Windows 运行依赖。当前交付是本地调试程序，不代表安装包、最低配置或签名分发已验收。

核心层保存真实状态；React 不自行宣称配置已保存或任务已完成。戳戳的短暂反馈与动画帧属于呈现状态，留在前端。浏览器预览只支持本地视觉交互，不能存密钥或调用模型。

### 桌宠窗口（2026-10-27）

初始为 180 × 180 逻辑像素的透明角色窗口；快捷入口为 300 × 360，展开面板为 440 × 560。三种尺寸只通过主窗口专用的 `set_shell_mode` 枚举命令选择，不增加通用窗口大小或位置 IPC 权限。原生阴影关闭；卡片背景和描边仅在快捷入口或面板显示。

Rust 根据窗口缩放比例转换成物理坐标，以角色底部中心为锚点调整尺寸和位置，并将窗口限制在当前显示器工作区内。碰到屏幕边缘时允许移动角色，优先保证入口可见。此逻辑不保存跨启动位置，不等同于完成跨屏 DPI 验收。待机矩形缩小，但尚未实现角色轮廓级鼠标穿透。

前端串行处理布局切换，调整失败时保留当前视图。角色点击打开/收起，移动超过阈值触发原生拖动；键盘 Enter/空格操作角色，Esc 收起。ChatPanel 保持挂载并隐藏以保留草稿；设置面板离开时卸载，不保留未保存密钥。收起不取消进行中的生成，也不会自动发送消息。

## 请求生命周期

1. 前端产生请求 ID，通过命令发送文字和专属输出 Channel。
2. Rust 检查主窗口、输入长度、用户远程授权、密钥、休息状态和正在运行的任务。
3. 解密密钥，组合固定人格说明、有限近期完整对话和本次输入。
4. SQLite 写入 pending 轮次；Rust 保留该请求的取消令牌。
5. DeepSeek SSE 文本增量通过 Channel 返回；界面只接受当前请求 ID 的增量。
6. 收到正常结束标记和 `[DONE]` 后，才保存为 complete。
7. 断流、取消、超时或长度上限保存为 error/cancelled，保留已收到的部分，并排除在未来上下文之外。

SQLite/DPAPI 操作放在阻塞任务池；数据库锁不会跨网络等待。全应用同时只运行一个生成任务；配置修改、清空记录在生成期间拒绝执行。单实例保护避免多个进程同时管理同一聊天状态。

“停止”取消本地等待并丢弃 HTTP 流，不能保证 DeepSeek 立即终止已开始的服务端计算，也不保证已处理部分免费。没有自动计费重试。抢先到达的取消请求会被短期记录，避免用户立即停止后请求仍然发出。快照带版本号，防止异步返回的旧状态覆盖新状态。

## DeepSeek 配置

- 地址固定为 `https://api.deepseek.com/chat/completions`，不允许界面随意更换密钥发送目的地。
- 默认模型 `deepseek-flash`，可选 `deepseek-v4-pro`；均显式关闭思考模式。
- 每次最大输出 2048 tokens；最大输入 4000 字符；最多携带 8 轮完整对话，历史和新输入合计最多 16000 Unicode 字符。这是应用字符预算，不是精确 token 计数。
- 连接超时 15 秒；流连续无数据 30 秒超时；整个生成最多 120 秒；输出文本最多 64 KiB。
- HTTP 重定向禁用；TLS 使用正常系统信任验证，不跳过证书检查。
- 不调用搜索、工具、截图、余额查询或模型列表 API。保存设置不会发起网络请求。

以上是首版可调整的工程限制，不是官方容量承诺，也不是延迟或费用实测。

官方依据（2026-10-26 核验）：[首次调用与模型名](https://api-docs.deepseek.com/)、[Chat Completions 与 SSE](https://api-docs.deepseek.com/api/create-chat-completion/)。模型名可能变化，后续应重新核验再更新适配层。

## 数据与隐私

数据库位于 Tauri `app_local_data_dir()/companion.sqlite3`，本机通常在 `%LOCALAPPDATA%/com.yokyora.helloworld/` 下；不放在源码仓库。SQLite WAL 的辅助文件也属于应用数据。

- `settings`：模型、加密密钥、远程发送授权、勿扰设置。
- `turns`：请求 ID、用户文本、已收到的回复、状态、创建时间。
- `user_version=1`：启动时初始化或检查版本；遇到更高版本拒绝打开，不覆盖数据库。上次异常退出的 pending 轮次标为 error。
- 界面最多展示最近 100 轮，数据库保留其余记录；上下文只使用符合预算的完整轮次。

首次默认不允许远程发送。用户需在设置中确认授权并主动发送消息。上传内容包括固定人格提示、本次消息和被选中的近期对话；当前不上传长期记忆、屏幕或其他应用状态。

密钥输入期间短暂经过前端和 IPC，保存后清空输入框；后端查询只返回 `hasApiKey`，不返回密钥。密钥以 DPAPI 当前用户范围加密，未使用允许整机用户解密的标志；原始密钥不写入日志。DPAPI 不抵御已经控制同一 Windows 账户的恶意程序，也不等同于聊天数据库加密。

聊天文本目前未加密。清空对话需要界面再次确认，删除本机业务记录，但不承诺取证级磁盘擦除，也不能删除服务端可能保留的数据。移除密钥仅移除本机存储项，不撤销服务商侧密钥；撤销需在 DeepSeek 平台完成。

前端 CSP 限制外部连接与远程资源；模型输出作为普通文字展示，不执行 HTML。所有模型请求来自 Rust。移除了原模板的外部打开能力授权；本轮没有任何模型驱动的系统操作。

## 人格、记忆与行为扩展

当前人格是固定提示约束，尚无人格生成或长期成长机制。当前 SQLite 对话记录不是长期记忆。

后续长期记忆模块应接在上下文构建与回复后的后台工作流之间，至少包含：类型、原始来源、来源时间、置信度、用户确认/纠正状态、保护标记。用户明确的禁令作为规则管理；不能因为容量压力被模型自行删除。

优先实现事实、偏好、近期事件与中文检索评估；根据实测召回质量决定是否增加向量索引。容量不足时优先提示或暂停写入，不能直接让模型永久删掉用户记忆。新增记忆外发需要更新授权说明。

当前勿扰持久化，暂停动画/戳戳，不阻止用户主动聊天；休息只在本次进程生效，并取消正在生成的回复。未来自动主动行为必须由 Rust 调度器检查勿扰、休息、频率和权限，不能仅靠界面隐藏。

窗口状态感知、屏幕内容理解、外部操作、日记和自主生活均未实现。未来 Windows 能力通过独立适配层接入，默认关闭；模型适配接口不拥有操作系统权限。
