# Hello World 桌宠数字生命 - Yokyora Studio

一个拥有专属记忆与稳定人格的桌面数字个体：屏幕识别是它的眼睛，桌宠是它的身体与表情，专属记忆是它的海马体，独立人格是它的灵魂。

## 一、需求

只做 Windows 桌面应用。先能陪着聊，再记得人，再看见屏幕，最后才允许它自己做事。

### 桌宠

- 透明、无边框、置顶，可拖动，记住上次位置
- 状态：待机、走动、被戳、思考、说话、发呆、闭眼
- 气泡显示它说的话，点气泡可接着聊
- 右键：聊天、设置、隐藏、退出
- 托盘：显示 / 隐藏、退出

### 对话

- 点击桌宠打开输入框，文字多轮聊天，带上最近若干条
- 人格：名字、性格、说话风格、口头禅
- 设置里填 API 地址、Key、模型名
- 可清空当前对话
- 聊天记录存在本机

### 记忆

- 长期保留。未到脑容量前不自动遗忘
- 每次对话结束后，AI 分析哪些内容需要记住
- 记住的内容写入本机数据库，每条带来源时间
- 下次聊天带上相关记忆
- 记忆页：查看、修改、删除
- 记忆可导出为本地文件
- 可设置脑容量，即记忆最大占用。即将到达上限时提示「脑容量告急」。新记忆写入时，AI 删掉过久且未被再次用到的旧记忆

### 屏幕感知

- 只知道当前窗口标题和进程名，不做截图、不做 OCR
- 按进程分成：文档、代码、浏览器、视频、游戏、其他
- 今天各类用了多久
- 判断是否空闲、是否全屏
- 可只记进程名，不记窗口标题
- 黑名单可增删，命中后不看
- 一键暂停，暂停时闭眼

### 主动与自主

- 心情：开心、平静、无聊、困。随聊天和当前软件变化
- 关系两档：初识、熟悉。聊得多了语气更亲近
- 打扰：安静 / 正常 / 活泼。每天有上限，被忽略就少说
- 主动时机：开工、久坐、空闲回来
- 全屏或用户标成专注的软件：不主动说话
- 空闲且事先允许时，按性格做一件小事，三选一：发呆走动、打开指定音乐、打开指定网页
- 白名单之外不打开。可打断、可关闭。用户说「别这样」写入永久记忆，以后不做

## 二、技术栈

| 项 | 定型 |
| --- | --- |
| 桌面 | Tauri 2 |
| 界面 | React + TypeScript + Vite |
| 桌宠 | 透明置顶窗口 + 序列帧，不做 Live2D |
| 对话 | OpenAI 兼容接口，Key 存在本机配置 |
| 数据 | SQLite，全在本机。记忆可导出，受脑容量限制 |
| 配置 | 本地文件：人格、API、脑容量、黑名单、专注软件、行为白名单 |
| 屏幕 | 只读活动窗口、空闲时间、是否全屏 |
| 操作 | 仅打开白名单内的应用或网址 |

不做：本地大模型、截图、OCR、语音、Live2D。

- 可清空当前对话
- 本机保存聊天记录
