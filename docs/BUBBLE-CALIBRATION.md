# 角色气泡校准

在原生桌宠中打开「设置 → 显示 → 校准气泡位置」，然后点击桌面角色的嘴部。保存后会回到设置，气泡显示在该位置附近。校准期间角色暂停动画；按 Esc 或点击「取消」保留原有位置。

锚点按 Live2D 模型分别保存到本机，重启后恢复。角色移动和缩放时自动换算位置，不需要重新校准。右侧空间不足时气泡转到左侧，两侧都不足时缩窄并限制在屏幕可用区域内。

## 更换模型

- 模型身份取自加载时 MOC 数据的 SHA-256。同一路径替换为不同 MOC 文件也会识别为新模型；只更换纹理、MOC 未变时保留原校准。
- 新模型若有明确命名为 `Head`、`Face`、`HitAreaHead` 或 `HitAreaFace` 的命中区域（名称或 ID，忽略大小写），使用其中心生成初始锚点。命中区域不一定准确对应嘴部，可以手动重新校准。
- 没有明确头部区域且未保存锚点时，暂不显示气泡；设置页提示校准。不会把旧模型的位置套到新角色上。
- 换回相同 MOC 文件时恢复它原有的锚点。

在「设置 → Live2D 角色」点击「导入模型」，选择模型的 `.model3.json` 文件，也支持使用同样格式的 `model.json`。保持它引用的纹理、动作、表情、物理等资源位于该文件夹内。导入成功后点击「切换角色」；模型列表和当前选择在重启后保留，内置 ATRI 始终可选。

导入会复制 JSON 引用的资源到应用本机数据目录，不修改原文件；复制完成后可移动原文件夹。重复导入相同资源包不会增加重复条目。当前支持 Cubism model3 格式，压缩包需先解压；实际可加载的 MOC 版本取决于应用内置 Cubism Core。

资源缺失、目录外引用或无效 JSON 会显示导入错误。单个资源上限 128 MB、资源包上限 512 MB；仅复制 JSON 引用的文件。角色加载失败时可重试，或从设置切回内置角色。

切换时先隐藏旧气泡，新模型完成加载后恢复自己的校准或头部默认位置；没有可用锚点则等待手动校准。导入和切换仅使用本机文件，不调用聊天 API。

气泡显示休息、勿扰等状态，以及本次运行中新完成回复的预览。长回复的完整内容在聊天面板查看。锚点校准仅操作本机，不调用聊天 API。
